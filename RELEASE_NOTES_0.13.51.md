# Trinity v0.13.51 - Crimson Desert build 2443

Compatibility hotfix for the August 16, 2026 Crimson Desert update.

## Fixed

- Restored Add Item after the game changed the internal item-value destructor.
- Restored the NPC Trust Multiplier after its setter function moved.

Add Item persistence, Stamina, Spirit, Fast Travel, Dye Equipment, the inventory catalog, and the overlay were verified in game.

## Safety

Back up your save before installing. Test Add Item with one ordinary non-quest item, then save and reload before wider use.
