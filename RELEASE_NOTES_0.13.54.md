# Trinity v0.13.54 - Crimson Desert 1.18.02

Compatibility update for Crimson Desert version 1.18.02.

## Fixed

- Restored Add Item after the game update changed the item-value destructor layout.
- Retained compatibility with the preceding Crimson Desert 1.18 executable.
- Revalidated inventory catalog discovery, Fast Travel, player-stat options, and Dye Equipment.
- Removed temporary storage tracing from the public release.

## Verified in game

- Add Item and item persistence after saving and reloading
- Infinite Stamina and Infinite Spirit
- God Mode
- Fast Travel
- Dye Equipment
- Inventory catalog and overlay

## Known limitation

- Abyss Gear socket changes may require saving and reloading before their effects become active.
- Open Storage and true hover-style Free Flight are not included in this release and remain follow-up work.
